# Compact instructions

When compacting, keep:
- full paths of every file created or changed, and what changed in each
- decisions made and why, including rejected options
- failed attempts, so they aren't retried
- the current state: what works, what's broken, exact last error
- concrete next steps
- user preferences stated in this conversation

Drop: long tool outputs, file contents that can be re-read, and exploration that led nowhere.
